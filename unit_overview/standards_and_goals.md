# Standards and Goals

## Unit Goal

Students will develop foundational computational thinking by using block coding in Minecraft Education to create, test, debug, and explain algorithms in an inclusive, access-forward learning environment.

## Essential Question

How can students use algorithms, debugging, and structured collaboration to solve coding problems in a digital environment, regardless of prior game experience, language background, or access needs?

## Big Ideas

- Algorithms are precise, ordered instructions.
- Sequence matters because computers follow instructions exactly.
- Debugging is expected and productive, not evidence of failure.
- Loops can make repeated actions more efficient.
- Collaboration is stronger when roles are explicit.
- Inclusive supports help students show computational thinking that might otherwise be hidden by interface or language barriers.

## Student Objectives

By the end of the unit, students will be able to:

1. create and test block-coded algorithms in Minecraft Education using MakeCode and the Agent;
2. use planning, prediction, and debugging strategies to revise code over multiple attempts;
3. explain how their code works using vocabulary such as algorithm, sequence, debug, agent, loop, coordinate, and efficient;
4. collaborate through Driver/Navigator roles while maintaining individual accountability;
5. reflect on how supports helped them access the task and improve their code.

## Standards Alignment

| Standard | Unit connection |
|---|---|
| NYS 4-6.CT.1 | Students develop, test, and revise programs using block coding. |
| CSTA 1A-AP-08 | Students model processes by creating and following algorithms. |
| CSTA 1A-AP-10 | Students develop programs with sequences and simple loops. |

| CSTA 1A-AP-14 | Students debug errors in algorithms or programs. |
| ISTE Student 5c | Students break problems into parts and use models to solve problems. |

## Why These Goals Matter

These goals are appropriate for Grade 4 because they connect visible Minecraft action to foundational computer science thinking. Students can watch the Agent move, compare that movement to their intended plan, and revise code. This makes abstraction more concrete.

The goals also matter because they push beyond task completion. A student who finishes a challenge but cannot explain the algorithm has not fully met the unit goals. A student who needs interface support but can plan, revise, and explain a sequence may be demonstrating stronger computational thinking than a completion-only score would show.
