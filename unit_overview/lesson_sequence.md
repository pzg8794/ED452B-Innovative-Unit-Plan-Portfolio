# Lesson Sequence

The unit is organized as four connected 45-minute lessons. Each lesson follows a predictable structure: warm-up, teacher model, guided practice, partner or independent coding, and formative closure.

## Lesson 1: Basic Moves

**Focus:** Minecraft access, MakeCode entry, Agent movement, short ordered sequences.

**Students learn to:**

- enter the correct Minecraft Education lesson;
- read or listen to NPC directions;
- open MakeCode;
- build a short movement sequence;
- predict before running code.

**Major supports:** projected click path, controls anchor chart, NPC read-aloud, Stop-Read-Predict routine, exit ticket.

## Lesson 2: Sequencing to Reach a Goal

**Focus:** longer ordered algorithms and planning before code.

**Students learn to:**

- decompose a visible path into steps;
- sketch or list a plan before coding;
- use Driver/Navigator roles;
- compare expected Agent movement to actual Agent movement.

**Major supports:** Plan Before You Code worksheet, sequence cards, partner talk, visual vocabulary.

## Lesson 3: Debugging and Revision

**Focus:** debugging as a procedure.

**Students learn to:**

- name what they expected the Agent to do;
- observe what actually happened;
- change one part of the code;
- retest and explain the fix.

**Major supports:** debugging protocol poster, bug-fix conference questions, tiered debug challenges, Expert Helper role for finishers.

## Lesson 4: Efficient Solutions and Reflection

**Focus:** loops, efficiency, final reflection.

**Students learn to:**

- compare repeated blocks to a loop;
- identify repeated actions;
- use a loop or shortcut to make code more efficient;
- explain how their coding improved across the unit.

**Major supports:** loop comparison example, planning sheet, reflection exit ticket, oral explanation option.

## Coherence Across Lessons

The lesson sequence moves from access to conceptual sophistication:

1. **Access and short sequences**
2. **Planning longer sequences**
3. **Debugging and revision**
4. **Efficiency and reflection**

This progression matches the rubric requirement that lessons coherently support development of content, conceptual, and procedural understanding over time.
