# Part 1 - Unit Plan Design

This section documents the initial ED452B Innovative Unit Plan design.

## Purpose

Part 1 establishes the unit's foundation:

- classroom context and rationale;
- inclusion-focused theoretical framework;
- long-term learning goals;
- standards alignment;
- assessment plan;
- connected lesson sequence;
- target-student supports.

## Core Design Claim

The unit uses Minecraft Education not simply as a motivating platform, but as an inclusive computer science environment. The main instructional problem is making sure students' computational thinking is not hidden by login friction, NPC reading load, unclear directions, executive-function demands, or unstructured collaboration.
