# Syllabus Alignment

This document explains how the Minecraft Education Innovative Unit Plan supports the major ED452B course expectations for inclusive instructional design.

## Course Focus

ED452B emphasizes instructional strategies for inclusive classrooms. The final unit responds to that focus by designing computer science instruction that anticipates learner variability rather than treating accommodations as after-the-fact fixes.

## How the Unit Aligns

| ED452B expectation | Unit response |
|---|---|
| Plan instruction for inclusive classrooms | The unit embeds Tier 1 supports for all students and Tier 2 scaffolds for target learners. |
| Use evidence to inform instruction | Placement transcripts and classroom challenge evidence drive the revision. |
| Support students with disabilities and diverse learning needs | The unit identifies three target-student profiles and connects supports to executive-functioning, language-processing, and regulation needs. |
| Use assessment to guide teaching | Assessment separates access, task interpretation, code accuracy, debugging, and explanation. |
| Reflect on implementation | The unit includes student-learning analysis and enactment commentary based on what happened during Minecraft instruction. |
| Collaborate professionally | The unit names how cooperating teacher evidence, classroom routines, student responses, and course readings informed the redesign. |

## Connection to Course Readings

The unit draws especially on Karten's inclusion framework and high-leverage practice orientation. The course work on functional assessment also shaped the unit: functional assessment should not only explain struggle, but should identify strengths, supports, and the conditions where a student succeeds. That principle is applied here by asking what classroom conditions helped students access Minecraft coding tasks.

## Submission Rationale

The repository format makes the unit easier to review because the major course expectations are separated into readable documentation files. The formal LaTeX unit plan remains the central artifact, while the Markdown files explain how the artifact meets the syllabus and rubric expectations.
