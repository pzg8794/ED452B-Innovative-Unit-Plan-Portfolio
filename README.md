## Overview

This repository documents the Part 1 Innovative Unit Planning submission for ED452B. The unit adapts **Minecraft Education: Coding FUNdamentals** into a Grade 4 inclusive computer science sequence for the IGNITE Computer Science and Digital Literacy rotation at Pine Brook Elementary.

The central design claim is:

> Students were not only struggling with coding. They were often struggling with access into the coding task. Inclusive computer science instruction must separate interface, language, reading, executive-function, and task-interpretation barriers from actual computational-thinking evidence.

The final unit therefore treats access as part of instruction and assessment, not as a separate accommodation after students fail.

## Final Unit Sequence

1. **Basic Moves** - access Minecraft Education, open MakeCode, move the Agent using a short sequence.
2. **Sequencing to Reach a Goal** - plan a longer ordered algorithm and test the Agent path.
3. **Debugging and Revision** - identify bugs, revise code, and explain one fix.
4. **Efficient Solutions and Reflection** - compare repeated code to loops and reflect on growth.

## Key Instructional Insight

Placement transcripts showed repeated access barriers:

- students skipped or misread NPC directions;
- students misunderstood the two-gold-plate challenge goal;
- students needed the Agent's movement possibilities clarified;
- students benefited from specific hints such as counting spaces or remembering that the Agent can float;
- students could sometimes complete a task before they could explain the code;
- open partner work needed structure so one student did not take over.

The final unit responds with:

- projected click-path routines;
- NPC read-aloud and task-goal restatement;
- Stop-Read-Predict-Run-Debug protocol;
- Driver/Navigator roles;
- planning sheets;
- multiple evidence sources for assessment;
- explicit target-student supports.
